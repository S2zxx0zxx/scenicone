## Tech Stack
Pure HTML5 + CSS3 + Vanilla JS. Zero frameworks. Zero dependencies.

## Performance Features
- Service Worker (offline support, smart caching)
- PWA installable (manifest.json)
- Core Web Vitals monitoring (js/perf.js)
- Error tracking (js/error-tracker.js)
- Analytics (js/analytics.js)
- Security layer (js/security.js)

## Developer Tools
Enable dev mode in browser console:
  localStorage.setItem('devmode', 'true')
Then refresh. You will see:
- Error overlay panel (bottom-left)
- Analytics panel (bottom-right)
- Performance report in console

View analytics report:
  window.scenicReport()
