# ScenicOne — Image Asset Guidelines

## Folder Structure
assets/images/
├── hero/          ← Full-screen hero images (1920x1080px min)
├── products/      ← Product photos (800x600px, 4:3 ratio)
├── about/         ← Team, artisan, workshop photos
├── icons/         ← UI icons (SVG preferred)
└── logo.png       ← Primary logo (transparent background)

## Naming Convention
- hero-main.jpg, hero-alt.jpg
- [category]-[number].jpg → table-01.jpg, sofa-02.jpg
- about/founder.jpg, about/artisan.jpg
- about/workshop-1.jpg through workshop-6.jpg

## Format & Size Rules
- Use WebP for all new images
- Hero: max 300KB
- Products: max 150KB each
- About/Gallery: max 200KB each
- Compress at: squoosh.app or tinypng.com
- Never upload: RAW, TIFF, BMP, uncompressed PNG > 1MB

## SEO Rules
- Every img tag must have descriptive alt text
- Format: alt="[Product Name] — Handcrafted [Material], ScenicOne Jodhpur"
